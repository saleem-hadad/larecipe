# LaRecipe 2.x

This version is deprecated. It receives security fixes only. Read the [3.x documentation](/guide/3.x) for new projects.

## Upgrading

Run `php artisan larecipe:upgrade` to convert your docs, then follow the upgrade guide for anything the command could not convert.
