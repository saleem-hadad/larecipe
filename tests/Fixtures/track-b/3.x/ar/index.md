# مقدمة

يحوّل LaRecipe مجلدًا من ملفات Markdown داخل تطبيق Laravel إلى موقع توثيق يقرؤه الناس والوكلاء معًا. تُعرض الصفحات بصيغة HTML للقرّاء، وبصيغة Markdown للوكلاء، ومن خلال خادم MCP لأدوات البرمجة.

## ما الذي تحصل عليه

- توثيق في المستودع نفسه الذي يضم الكود، يُراجَع في طلب الدمج نفسه.
- صفحة تخبرك متى تغيّرت، وما الذي غيّرها، ومن اعتمد التغيير.
- بحث يجيب أثناء الكتابة، وميزة السؤال لما لا يجده البحث.
- كل صفحة متاحة بصيغة Markdown عبر الرابط `.md` ومدرجة في `llms.txt`.
